# 강민규 교수 홈페이지

충북대학교 의과대학 내과학교실 강민규 부교수(충북대학교병원 알레르기내과)의 소개 홈페이지. 진료 차트를 열고 서식을 넘기며 연구, R&D 프로젝트, 임상시험, 특허, 논문, 이력, 보도를 봅니다.

- 정적 사이트입니다. `index.html` + `assets/` + `attachments/` 만 있으면 어디서든 열립니다.
- 원본과 빌드 스크립트는 로컬 작업 폴더 `homepage/design/` 에 있습니다. 내용을 고친 뒤 `node build-chart.mjs && node build-site.mjs` 로 이 폴더를 다시 만들고 커밋하면 GitHub Pages 에 반영됩니다.
